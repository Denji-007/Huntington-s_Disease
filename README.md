# Huntington's_Disease
To check your physical quick response for determining Huntington's Disease thorough some terminal based easy games.
This project contains mainly two games to check you response speed and accuracy.


The First Game is "Target Clicking Game":-
                                            where an X symbol appears in the screen and tell you to press w for up , a for left, s for down or d for right. First it asks you name and welcomes you, then the game starts. There is total 10 rounds in this game and depending on your result it tells you your speed and accuracy and if you should consult a docor for further medical checkup or just be cautious ...


The Second Game is "Pattern Memory Game":-
                                            where A, S, D, F, G, H, J, K , toal of 8 keys appear randomly on the screen starting with 3 letters and increasing in each round. After displaying the letters it disappers and 3-2-1 countdown starts and after the countdown stops you have to memorize the number and type in the terminal to ge to the next round. Fail in one round and the game is over. And The result is shown in the display.
